# PEDAGOGY — vox-stark-linear

## Concept chain
1. Four n=2 states are all degenerate at -3.4 eV. Normal (non-degenerate) perturbation theory fails: denominator = 0.
2. Fix: build the 4×4 matrix of the perturbation (eεz) within the degenerate subspace and diagonalize it.
3. Parity selection rule: z is odd; ⟨ψ|z|ψ⟩ = 0 if ψ has definite parity. All diagonal entries vanish.
4. m_ℓ conservation: z doesn't change m_ℓ. Kills all off-diagonal pairs with Δm_ℓ ≠ 0.
5. Only ⟨2s|z|2p₀⟩ = -3a₀ survives (2s even, 2p odd, same m_ℓ=0).
6. The surviving 2×2 block gives eigenvalues ±3a₀eε and eigenstates (|2s⟩ ± |2p₀⟩)/√2.
7. These "good states" are lopsided clouds — they have a permanent electric dipole along z → linear Stark shift.
8. 2p±1 decouple, stay at E₂ → middle line is doubly degenerate → twice as bright.
9. Ground state has no partner → quadratic Stark effect only (much smaller).

## Misconception barriers
- "Four states → four lines" — NO: two states share the same unshifted energy.
- "All states shift linearly" — NO: only the two that mix; the symmetric 2p±1 states don't shift at first order.
- "Ground state also has a linear Stark effect" — NO: no degenerate partner → only quadratic (second-order).
